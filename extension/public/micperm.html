Microphone blocked

Chrome said:

Allow the mic for this extension in site settings, then try again. On a Mac, also check System Settings → Privacy & Security → Microphone → Chrome — if Chrome itself has no mic access, no site can.

No microphone found

Chrome can't see an audio input device — this isn't a permission problem.

On Windows: Settings → Privacy & security → Microphone — turn on Microphone access and Let desktop apps access your microphone (off silently causes exactly this). Then check Settings → System → Sound → Input lists a device; if not, plug in a headset or webcam.

Walkthroughs record fine without a mic — the take just carries no narration.
